# DataSkillz Product Design Skills

An independently authored Product Design skill suite for Codex. It provides a router and focused workflows for design briefing, UX research, audits, visual ideation, URL and image-to-code prototyping, visual QA, sharing, and reusable design context.

## Skills

- `index` — routes Product Design work.
- `get-context` — confirms a lightweight design brief.
- `research` — researches current UX friction.
- `audit` — audits captured product flows.
- `ideate` — creates distinct visual directions.
- `url-to-code` — recreates a permitted live site locally.
- `image-to-code` — builds from a selected visual target.
- `design-qa` — compares a prototype with its source design.
- `share` — deploys a verified prototype.
- `user-context` — maintains durable design references.

Install this directory as a local Codex plugin or copy individual folders from `skills/` into your skills directory.
