# Product Design Context

Use this for setup, onboarding, remembering references, reviewing saved context, and updating design preferences. Persist context only when a safe writable plugin state location is available; otherwise use it for the current conversation and clearly say it cannot be saved for future runs.

Keep context curated and durable. Useful entries include product URLs, codebase paths, Storybook or component documentation, screenshots, Figma files, tokens, brand assets, preferred browser/capture tools, and sharing targets. Never save secrets, credentials, private tokens, or copied customer data.

Store image references with descriptive filenames and state what each reference is, when it should be used, and the date it was added. During future work, inspect only the subset relevant to the current task rather than every saved item.
