# Analyze Data Quality

Profile the source before using it: identify grain, keys, coverage period, freshness, nulls, duplicates, outliers, referential integrity, and reconciliation with authoritative totals. Test joins for row multiplication and compare definitions across sources. Report risks, their likely impact, what remains usable, and the specific remediation or caveat required.
