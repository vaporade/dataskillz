# Build Dashboard

Define the audience, decision, source, refresh expectation, and primary questions first. Use compact, interpretable measures, appropriate chart types, clear filters, visible definitions, and useful empty/loading/error states. Keep each visual tied to a question, verify calculations and interactions, and include source and freshness context.
