# Build Report

Write for a stated audience and decision. Lead with the answer and supporting evidence, then present methodology, analysis, limitations, and recommended actions. Every important number must be traceable to a source or calculation. Use visuals when they clarify a relationship better than prose, and distinguish facts, inferences, and assumptions.
