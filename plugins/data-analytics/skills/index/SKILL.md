# Data Analytics Router

Use this entrypoint for questions requiring quantitative evidence. First establish the decision, audience, metric definitions, relevant time range, and authoritative sources. Do not treat a requested output as evidence.

Route to `$gather-business-context` when crucial framing is missing; `$analyze-data-quality` before relying on suspect data; `$metric-diagnostics` for a movement or anomaly; `$product-business-analysis` for a decision; `$design-kpis` for measurement design; `$market-sizing` for TAM/SAM/SOM; `$build-dashboard`, `$build-report`, `$kpi-reporting`, `$visualize-data`, or `$jupyter-notebooks` for deliverables; and `$validate-data` before high-stakes handoff. Use conversion, PDF, sharing, publishing, or refresh workflows only after an artifact exists.
