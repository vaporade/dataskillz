# Data Visualization

Choose a chart based on the analytical question, comparison, and supported takeaway. Preserve honest scales, legible labels, accessible contrast, meaningful sorting, and appropriate annotations. Avoid decorative complexity and misleading encodings. Check calculations, units, source notes, responsive behavior, and the chart's readability at its actual display size.
