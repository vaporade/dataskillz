# Jupyter Notebooks

Make notebooks reproducible: state inputs and assumptions, separate extraction from transformation and analysis, avoid hidden state, retain outputs needed for review, and use deterministic seeds when appropriate. Include concise narrative around each analytical step, validate executable order from a clean kernel, and keep credentials out of the notebook.
