# Metric Diagnostics

Reproduce the metric exactly, define the baseline, validate the change, then decompose it by the most plausible dimensions. Check instrumentation, freshness, definition changes, population shifts, and known releases before claiming causality. Label findings as verified, likely, or unresolved; include the next test for unresolved drivers.
