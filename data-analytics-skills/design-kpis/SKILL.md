# Design KPIs

Start from the decision and value created. Define a small set of outcome metrics, leading indicators, guardrails, ownership, cadence, formula, grain, source, target logic, and failure modes. Avoid vanity metrics and targets without a baseline or operating action. Make trade-offs and measurement limitations explicit.
