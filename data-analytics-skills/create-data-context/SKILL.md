# Create Data Context

Capture durable instructions that improve future analytical work: source preferences, metric definitions, audience expectations, style, quality standards, and delivery conventions. Keep it concise, scoped, editable, and free of secrets or transient details. Confirm whether the user wants a draft, a local artifact, or persistent installation before writing it.
