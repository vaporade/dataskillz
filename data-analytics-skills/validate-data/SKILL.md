# Validate Data Analysis

Check that the question, source, definitions, transformation logic, calculations, visual encodings, and conclusion all agree. Recompute key results independently where practical, verify time windows and denominators, inspect assumptions, and identify material limitations. Fix supported errors; otherwise label the deliverable blocked or qualified rather than overstating certainty.
